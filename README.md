# بوت عبد القادر - 10%

بوت مراقبة لعملات Binance يرسل تنبيه تليجرام فقط (لا يشتري ولا يبيع).
يشتغل من 6 مساءً إلى 2 فجراً بتوقيت بغداد، بحد أقصى صفقتين باليوم، هدف 10% ووقف 3%.

## التشغيل
1. `pip install -r requirements.txt`
2. انسخ `.env.example` إلى `.env` وضع `TELEGRAM_TOKEN` (وأرسل `/start` لبوتك ليكتشف `TELEGRAM_CHAT_ID` تلقائياً).
3. تجربة تليجرام: `python main.py --test`
4. تجربة البوت بأي وقت: `python main.py --anytime`
5. التشغيل العادي: `python main.py`

## تنبيه
- لا ترفع ملف `.env` إلى GitHub أبداً (فيه التوكن).
- مفاتيح Binance اختيارية، وإن وضعتها فاجعلها "قراءة فقط".
- التنبيهات ليست نصيحة مالية، ونسبة النجاح غير مضمونة. جرّب بحساب وهمي أولاً.
